# Planning Instagram

Telegram Mini App для планирования ленты Instagram: сетка 3×N как в профиле, добавление фото из галереи, перетаскивание, подписи, даты и статусы постов.

Фото и данные хранятся на устройстве (IndexedDB).

## Запуск
1. Включите GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
2. В @BotFather создайте бота (`/newbot`), затем `/newapp` или `/setmenubutton` и укажите ссылку на страницу.
